# betta apps

Small apps and tools, each doing one job.

- **betta life**: food, weight, steps, gym sessions, recipes and meal plans, with an MCP server so Claude can read and write it from any conversation.
- **betta mcp**: one MCP connector per service (Google, Slack, WhatsApp, Signal, Telegram and more), for Claude or any AI app that takes connectors.
- **betta agents**: what the Claude agents did, and what needs a person.
- **deps-factory**: keeps every app's dependencies up to date, so nobody has to.

Every app is built with betta design, ships as a container image, and is tested before anything is published.
